# HH.ru Vacancy Search Bot

Telegram-бот для поиска вакансий на HH.ru с возможностью фильтрации, добавления в избранное, истории поиска и подписок на новые вакансии.

## Особенности

- 🔍 Поиск вакансий по ключевым словам
- ⭐ Добавление вакансий в избранное
- 📋 История поиска
- 🔔 Подписки на новые вакансии
- 🏙️ Фильтрация по городу, зарплате, опыту, графику и типу занятости
- 🛡️ Безопасная обработка данных и переменные окружения
